# UI Adaptativa Multiplataforma

Actividad Flutter independiente con una pantalla de ajustes que utiliza componentes Cupertino en iOS y Material Design en las demás plataformas. La selección de la interfaz se hace con `Platform.isIOS`, y los switches conservan su estado al interactuar.

## Requisitos

- Flutter instalado y configurado en el PATH.

## Ejecutar las pruebas

Desde esta carpeta:

```powershell
flutter pub get
flutter test
```

## Ejecutar la aplicación

```powershell
flutter run
```
